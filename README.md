# omegle-io

A small Node.js script that uses Puppeteer (via `puppeteer-real-browser`) to send messages at bulk in https://omegleweb.io/  by automating browser actions.

**Install**

- Install dependencies:

```bash
npm install
```

**Usage**

- Edit the variables in index.js:
`SAME_COUNTRY`
`MESSAGE`
`INTERESTS`


- Run the main script:

```bash
node index.js
```

**Notes**

- This repository is intentionally minimal. Edit `index.js` to change behavior or add configuration as needed.
